\section{Conclusion and future work}
\label{sec:conclusion}

Detecting lateral movement via anomalous-edge detection over dynamic authentication graphs
provides an important foundation for network defense. However, conventional formulations
operating strictly over host-to-host edges discard the client execution context available
at Zero Trust policy decision points. By decomposing requests into a 5-node relational chain
and introducing an explicit client-configuration node, the approach enables detection of
credential reuse from unfamiliar tools as a structural anomaly.

Furthermore, the findings emphasize 2 broader architectural requirements for continuous
streaming detectors. First, streaming memory updates must be decoupled from the detector's
own predictions through an external commit gate to prevent runaway baseline drift and
adversarial poisoning. Second, synthetic security benchmarks require systematic leakage audits
to prevent models from exploiting unconstrained synthetic artifacts. On the verified benchmark,
the 5-node TGN clears the single-feature baseline floor on lateral movement by a substantial
margin under one-class training.

First, evaluating the architecture across multi-source enterprise testbeds such as the AIT
corpus offers opportunities to test cross-environment generalization with real packet-derived
TLS fingerprints. Second, evaluating bipartite degradation directly on traditional benchmarks
like LANL under standardized community splits provides a direct point of comparison for the
incremental utility of fine-grained contextual nodes. Finally, incorporating hardware-assisted
trusted execution environments to secure serving state and policy feedback loops represents a
natural step toward resilient production deployment.
