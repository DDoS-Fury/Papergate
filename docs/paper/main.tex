\begin{abstract}
Detecting lateral movement as anomalous-edge detection over a temporal graph of
authentication events is an established line of work. We argue that the substrate,
not the task, is where the remaining headroom lies. A Zero-Trust policy decision
point observes strictly more than a host-to-host authentication log: for every
request it sees the client network origin, the client's TLS configuration
fingerprint, the device posture identity, the authenticated principal and the
requested asset. We model this as a five-node causal chain per request and evaluate
a Temporal Graph Network over it under a protocol that keeps the deployment honest:
one-class training on benign traffic only, event-by-event chronological scoring, and
a memory-commit gate driven by an \emph{external} policy engine rather than by the
model's own verdict. Two properties follow from the extra nodes. Credential reuse
from an unfamiliar client tool becomes expressible as an anomalous
configuration-to-principal binding, a class not representable on a host-to-host
graph. Furthermore, the anti-poisoning commit gate provides verifiable resilience against
adversarial baseline drift, as entity memory advances strictly on events admitted by
external policy. We further report an automated label-leakage audit for the synthetic
generator, along with an empirical case study on PicoDomain, where all five nodes are
grounded in real enterprise telemetry, providing JA3 fingerprints alongside Kerberos principals.
\end{abstract}
